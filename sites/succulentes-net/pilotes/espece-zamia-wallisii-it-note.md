  - Calonje, López-Gallego & Castro 2018 (Phytotaxa 385(2), PDF lu) : « the broadest leaflets in the genus », maximum 11 folioles.
- Divergences exposées dans la page : néotype (Flora 2001) / lectotype S (WLoC, IPNI ; Lindström 2009 non lu ; supersession du néotype présentée comme probable) ; 2-5 paires (Flora) / jusqu'à 8 paires (Braun) ; description de la Flora presque identique à celle de *Z. dressleri* (Stevenson 1993) hormis le pétiolule.
