## Erreurs relevées sur la page EN 16512 (modifiée aujourd'hui par un autre agent ; non touchée)
- *C. seemannii* placé « in section Cycas — the same section as *C. rumphii*, *C. thouarsii*, *C. media* » : *C. media* n'a pas de graines flottantes ; le groupe à graines flottantes est la sous-section *Rumphiae* (Hill 1994 ; LHS 2009).
- Noms « namule » (fidjien), « tongo » (tongien), « Fiji sago palm », « namele … national symbol » : non attestés dans les sources consultées (Species+ : *logologo*).
- Aire « possibly Solomon Islands and Samoa », flux génique avec *C. rumphii* aux Salomon : non sourcés ; WLoC : Fidji, Nouvelle-Calédonie, Tonga, Vanuatu.
- Tronc « 15-25 cm », « 80-150 pairs of leaflets », « single annual flush », cônes mâles « 30-50 cm » : non sourcés ou différents de dL&A (14-30 cm ; 65-150 par côté ; 32-60 cm).
- Hill (1994) « based on … leaflet shape and seed characters » : non vérifiable (texte inaccessible) ; dL&A rapportent un critère de mégasporophylle pour *micronesica*.
